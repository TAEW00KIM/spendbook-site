Claude, ChatGPT에 연결하기

Claude나 ChatGPT에게 내 가계부를 묻고, 거래를 기록하게 하는 방법

Claude(claude.ai)와 ChatGPT는 가계부를 커넥터로 연결할 수 있습니다. 연결할 때 브라우저에 8자리 코드가 뜨고, 그 코드를 가계부 앱에서 승인하면 끝납니다. 비밀번호나 토큰을 따로 복사할 필요가 없습니다.

연결 주소
https://spendbook.kimtaewoo.dev/mcp

준비

  • 가계부 앱에 Apple로 로그인되어 있어야 합니다. 로그인 없이 쓰는 경우에는 거래가 기기에만 있어 연결할 수 없습니다.
  • 연결은 컴퓨터 브라우저에서 하는 것이 편합니다. 승인은 iPhone의 가계부 앱에서 합니다.

Claude (claude.ai)

  1. claude.ai에서 설정 > 커넥터를 엽니다.
  2. 커스텀 커넥터 추가를 누르고, 이름은 가계부, 주소는 위의 연결 주소를 넣고 추가합니다.
  3. 목록의 가계부에서 연결을 누릅니다.
  4. 브라우저에 8자리 코드가 뜨면 아래 “앱에서 승인하기”로 넘어갑니다.

ChatGPT

  1. 브라우저에서 chatgpt.com/plugins를 엽니다.
  2. + 단추를 누르고 Add custom MCP server를 고릅니다.
  3. 이름은 가계부, 연결(Connection) 주소는 위의 연결 주소를 넣고, 인증은 OAuth를 고릅니다.
  4. 안내가 나오면 I understand and want to continue, 이어서 Create as a plugin을 누릅니다.
  5. 브라우저에 8자리 코드가 뜨면 아래 “앱에서 승인하기”로 넘어갑니다.

커스텀 MCP 서버 추가는 ChatGPT 플랜에 따라 보이지 않을 수 있습니다. 메뉴 이름은 Claude와 ChatGPT 화면이 바뀌면 달라질 수 있습니다.

앱에서 승인하기

  1. iPhone에서 가계부를 열고 설정 > 에이전트 연결 > 웹 연결 승인 > 코드 입력을 누릅니다.
  2. 브라우저에 뜬 8자리 코드를 넣습니다. 코드는 10분 동안 쓸 수 있습니다.
  3. 어느 서비스가 연결하려는지(예: Claude, ChatGPT)와 돌아갈 곳, 요청한 범위를 확인하고 허용할 범위를 고릅니다. 요청한 범위보다 낮게만 줄 수 있습니다.
  4. 승인을 누르면 브라우저가 저절로 Claude나 ChatGPT로 돌아가 연결이 끝납니다. 마음에 들지 않으면 거절을 누르세요.

직접 시작한 연결이 아니면 승인하지 마세요. 코드를 남에게 보내지 마세요.

권한 세 단계

범위할 수 있는 일
조회만잔액, 거래, 카드 청구, 할부, 예산을 보고 요약합니다. 기록은 바꾸지 못합니다.
기록까지조회에 더해 거래를 새로 기록하고, 기존 거래의 메모, 카테고리, 이름을 고칩니다.
전부거래 삭제, 잔액 맞춤, 계좌와 분류 규칙 변경, 카드 내역 반영까지 합니다. 삭제, 잔액 맞춤, 계좌 수정은 하루 20번까지입니다. 믿는 에이전트에만 주세요.

처음에는 조회만으로 시작하고, 필요할 때 더 높은 범위로 다시 연결하는 것을 권합니다. 에이전트가 바꾼 내용은 변경 기록에 남고 되돌릴 수 있습니다.

Claude Code, Codex 같은 도구

브라우저 승인이 없는 도구는 앱에서 만든 토큰으로 연결합니다.

  1. 가계부 앱에서 설정 > 에이전트 연결 > 토큰 만들기를 눌러 이름과 범위를 고릅니다(범위는 위 세 단계와 같습니다).
  2. 만든 직후 토큰이 한 번만 보입니다. 닫기 전에 명령 복사로 Claude Code에 붙여 넣을 명령을 복사하세요. 닫으면 다시 볼 수 없고 새로 만들어야 합니다.
  3. 터미널에 붙여 넣어 실행합니다. 복사한 명령은 아래와 같은 모양입니다(<토큰> 자리에 토큰).
claude mcp add --transport http ledger https://spendbook.kimtaewoo.dev/mcp --header "Authorization: Bearer <토큰>"

다른 에이전트는 같은 주소와 토큰을 Authorization: Bearer 머리글로 넣으면 됩니다. 토큰은 최대 10개까지 만들 수 있습니다.

토큰은 비밀번호처럼 다루세요. 화면이나 채팅에 붙여 넣지 마세요. 새고 나면 앱에서 폐기하고 다시 만드세요.

연결 끊기

가계부 앱 설정 > 에이전트 연결 > 연결된 앱에서 밀어서 해제하면 바로 끊깁니다. 토큰으로 연결한 도구는 같은 화면의 토큰 목록에서 폐기합니다. Claude나 ChatGPT 쪽에서 커넥터를 지워도 됩니다.

알아 두기

  • 연결되면 그 Claude나 ChatGPT 계정을 쓰는 사람은 이 가계부의 거래를 볼 수 있습니다(범위가 높으면 기록하거나 바꿀 수도 있습니다).
  • Claude나 ChatGPT가 가져간 내용은 그 서비스의 방침에 따라 처리됩니다. 자세한 내용은 개인정보 처리방침 4를 보세요.
  • 연결마다 분당 호출 120번, 분당 쓰기 60건, 거래 목록은 한 번에 200건까지입니다.
  • 저장 공간(계정당 50MB)이 가득 차면 새로 기록하는 일이 막힙니다. 읽기와 삭제는 됩니다.
